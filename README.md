# Dorifto 🏎️

3D дрифт-аркада для Android (Three.js у WebView).

## Як отримати APK
Кожен push у `main` запускає GitHub Actions: збирає гру й публікує `Dorifto.apk` у **Releases**.

## Керування
- **ГАЗ / ГАЛЬМО / РУЧНИК** — праворуч, **◀ ▶** — ліворуч
- Занос: ручник або різкий поворот на газу
- Під час дрифту: кнопка в бік повороту — кут більший, протилежна — рівніше; відпусти газ — вийдеш із заносу
- ↺ — повернути машину на трасу, 🎥 — змінити камеру

На ноуті: стрілки/WASD, пробіл — ручник, R — скинути, C — камера.

## Структура
- `web/src` — код гри (`game.js`, `index.html`), збирається esbuild у `app/src/main/assets`
- `app/` — Android-обгортка (WebView)
